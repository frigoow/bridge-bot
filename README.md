# bridge-bot

Contract Bridge **card-play** bot built on the same architecture as our
[Manille](https://github.com/frigoow/manil-bot) and [Belote](https://github.com/frigoow/belote-bot)
bots, sharing game-independent C++ and Python infrastructure through the
[cardbot-framework](https://github.com/frigoow/cardbot-framework) git submodule (`cardbot-framework/`).

Card play only: every deal starts with all 52 cards dealt and a fixed contract (either generated by a fast natural contract assigner for self-play training or loaded from real tournament PBN files).

## Layout

| Path | What |
|---|---|
| `cpp/bridge/` | C++20 Bridge card-play engine (`card.h`, `scoring.h`, `deal.h`, `deal_gen.h`), exact 2-seat/3-seat world sampler (`sampler.h` over `cardbot::HiddenDeal<13>`), exact double-dummy alpha-beta endgame (`endgame.h` over `cardbot::EndgameSolver`), Bo Haglund's DDS wrapper (`dds_solver.h/.cpp`), heuristic baseline (`rule_agent.h`), canonical-suit neural encoder with BeliefNet targets (`encoder.h/.cpp`), hybrid search (`search.h/.cpp` over `cardbot/search.h`), and agent factory (`agents.h/.cpp`) |
| `cpp/tools/duel.cpp` | `bridge_duel`: multi-threaded duplicate-deal harness reporting WBF IMPs/board ± 95% CI, tricks/board ± 95% CI, win/tie/loss %, tricks lost vs double-dummy par (`--dd-bench`), and real PBN board support (`--pbn`) |
| `cpp/python/bridge_module.cpp` | `bridge_cpp` pybind11 module (`BatchEnv`, `SuitBatchEnv`, `NtBatchEnv`, `QGruModel`, `FastPolicyModel`, `BeliefModel`, `BridgeGame`, `Agent`, DDS helpers, PBN loader, `duel_imps`) |
| `cpp/tests/` | C++ unit tests: `test_rules`, `test_sampler`, `test_dds` (cross-checks `BridgeGame` + `EndgameSolver` 100% against Bo Haglund's DDS), `test_search` |
| `python/bridge/` | DMC self-play training (`train_dmc.py`, Q-GRU + BeliefNet via `cardbot.train.dmc`), 6×/24× canonical suit-permutation augmentation (`suit_perm.py`), and `FastPolicy` distillation (`train_distill.py` via `cardbot.train.distill`) |
| `tools/opponents/` | Established online opponent adapters and cross-engine duplicate-deal arena (`ben_player.py`, `arena.py`) |
| `third_party/dds/` | Bo Haglund's Double Dummy Solver ([dds-bridge/dds](https://github.com/dds-bridge/dds), Apache-2.0, submodule) |
| `cardbot-framework/` | Shared framework ([frigoow/cardbot-framework](https://github.com/frigoow/cardbot-framework), submodule) |
| `external/` | Gitignored external opponents fetched by `scripts/fetch_opponents.sh`: **BEN** ([lorserker/ben](https://github.com/lorserker/ben), GPL-3.0, ONNX models + BBO PBN boards) and **bridge_learning** ([hanyuu11/bridge_learning](https://github.com/hanyuu11/bridge_learning), AlphaMu / PIMC / RuleBasedDefender) |

## Build & Test

```bash
python3 -m venv .venv
.venv/bin/pip install -r python/requirements.txt
.venv/bin/pip install --no-build-isolation -e cardbot-framework/python

.venv/bin/cmake -B build -S cpp -DCMAKE_BUILD_TYPE=Release -DBRIDGE_PYTHON=ON \
    -DPython_EXECUTABLE=$PWD/.venv/bin/python \
    -Dpybind11_DIR=$(.venv/bin/python -c 'import pybind11; print(pybind11.get_cmake_dir())')
.venv/bin/cmake --build build -j

.venv/bin/ctest --test-dir build --output-on-failure
.venv/bin/python -m pytest python/tests -v
```

Fetch established external opponents (BEN ONNX models + BBO PBN boards, and `bridge_learning`):

```bash
./scripts/fetch_opponents.sh
```

### Running Duels & Arena

```bash
./build/bridge_duel --a pimc_dds:16 --b rule --deals 100 --threads 16 --dd-bench

```

## Training Pipeline

```bash
# 1. Train Q-GRU (+ BeliefNet) via DMC self-play with 6x/24x suit-permutation augmentation
PYTHONPATH=build:python .venv/bin/python -m bridge.train_dmc \
    --mode all --episodes 5000000 --envs 1024 --train-belief \
    --out checkpoints/q_all.bin --out-belief checkpoints/belief_all.bin

# 2. Distill Q-GRU into FastPolicy (BRP1) for microsecond C++ rollouts
PYTHONPATH=build:python .venv/bin/python -m bridge.train_distill \
    --mode all --teacher checkpoints/q_all_best.pt --out checkpoints/fast_all.bin

# 3. Evaluate full hybrid search (FastPolicy + Q-GRU blend + BeliefNet + DDS endgame)
./build/bridge_duel \
    --a "search:48:dds6:rex6:fast=checkpoints/fast_all.bin:q=checkpoints/q_all_best.bin:qb=0.25:belief=checkpoints/belief_all.bin" \
    --b pimc_dds:16 --deals 200 --threads 16
```
